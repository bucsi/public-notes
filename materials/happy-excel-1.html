Task (Advanced Matura Exam 2020 fall)

2. Robot Race

Building and programming robots is becoming increasingly popular among students, resulting in more national and international robot races. In this exercise, you will process the results of such a race. The data is provided in the file results.txt, which is UTF-8 encoded.

Your task is to analyze and display the data using a spreadsheet processor. #### General Guidelines - Perform auxiliary calculations to the right of column Q. - Use formulas, functions, or references to ensure results remain accurate even if source data changes. - If a part relies on a previous step, and that step was incomplete, use a reasonable result to proceed and earn marks for the dependent parts. #### Step-by-Step Instructions

1. Importing the Data
  • Import results.txt (UTF-8 encoded, tab-separated) into the spreadsheet starting from cell A1.
  • Save your work as robotrace in the spreadsheet’s default format. Notes:
  • The race includes up to four rounds.
  • A higher score is better.
  • In case of equal scores, lower time wins.
  • Score data: Range A1:H26
  • Time data (in seconds): Range A28:G53
  • A time value of 0 means the robot could not start the round.
  • Robots that could not start in any round are not included in the table.
2. Highest Score Per Team
  • In range F2:F26, determine the highest score achieved by each team.
3. Total Scores and Times
  • In range G2:G26, calculate the total score for each team (sum of four rounds).
  • In range G29:G53, calculate the total time (in seconds) for each team (sum of four rounds).
4. Highlight Zero Time Entries
  • Apply conditional formatting to range B29:E53 to highlight cells with a value of 0 using a grey background.
5. Lowest Valid Time Per Team
  • In range F29:F53, determine the lowest time per team.
  • Ignore 0-second values when calculating the minimum time.
  • Use a formula that can be copied without modification.
6. Race Score (Top 3 Rounds Only)
  • In range H2:H26, calculate the sum of the three highest scores (out of four) for each team.
  • Label this column as race score.
7. Auxiliary Table for Final Results
  • In range J1:M26, create a summary table:
    • Column K: Team names
    • Column L: Race scores
    • Column M: Total times
  • Use formulas to pull data into this table. Ensure formulas are easily copied across rows.
8. Ranking the Teams
  • Sort the rows of range J2:M26:
    • First by race score (descending).
    • Then by total time (ascending) in case of a tie.
  • The winning team should appear at the top.
9. Count Teams by Score Threshold
  • In cell O2, enter any race score value.
  • In cell P2, use a formula to count how many teams reached or exceeded the race score entered in O2.
